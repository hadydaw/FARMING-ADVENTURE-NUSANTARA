# Panduan Uji APK Dev di HP

**Unduh:** https://github.com/hadydaw/FARMING-ADVENTURE-NUSANTARA/releases/tag/dev-latest
(file `FarmingAdventureNusantara-dev-<nomor>.apk`; pre-release otomatis dari `main`)

## Pasang
1. Buka tautan di atas di browser HP, unduh file `.apk`.
2. Buka file; bila diminta, izinkan "Pasang aplikasi tidak dikenal" untuk browser/pengelola berkas tersebut.
3. Ketuk Install. Aplikasi bernama **FAN Dev** (paket `.dev`, tidak bentrok dengan rilis resmi).
4. Bila gagal karena konflik tanda tangan: hapus FAN Dev lama lalu pasang ulang.

## Yang harus terlihat (layar boot, BUKAN gameplay)
- [ ] Aplikasi terbuka dan otomatis **landscape**
- [ ] Ada pulau kecil 3D (pohon + rumah) yang berputar pelan, tidak patah-patah
- [ ] Judul "Farming Adventure Nusantara", versi `0.1.0-dev.N`, renderer `gl_compatibility`, FPS
- [ ] Tombol bahasa merespons sentuhan: teks berganti Indonesia ↔ Inggris
- [ ] Tidak crash saat keluar-masuk aplikasi

## Laporkan
Kirim hasil centang di atas, tipe HP/Android, FPS yang tampil, dan tangkapan layar bila ada masalah. Status "lulus di HP" baru dicatat setelah Anda melapor.
